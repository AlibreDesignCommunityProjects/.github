## **Alibre Design Community Projects**

AI/LLM assistance may be used during the design and development of projects maintained within this GitHub organization. This assistance may include support with source code generation, code review, refactoring, debugging, algorithm development, CAD and computational design workflows, automation, scripting, technical research, documentation, examples, comments, project descriptions, release notes, and other supporting development content.

**Stephen S. Mitchell is the sole CAD designer and developer of the projects maintained within this GitHub organization.** The use of AI/LLM tools does not replace or represent independent authorship, design authority, engineering judgment, or project ownership.

All CAD design intent, geometry development, modeling methodology, computational design logic, software architecture, project direction, feature selection, implementation strategy, public APIs and interfaces, algorithms, automation workflows, integration decisions, testing, debugging, packaging, deployment, maintenance, and final validation are directed, reviewed, and performed by **Stephen S. Mitchell**.

AI/LLM-assisted source code, scripts, algorithms, CAD automation logic, computational design methods, and implementation suggestions are treated as development aids. Any AI/LLM-assisted material incorporated into a project is manually reviewed, modified as necessary, tested, debugged, and integrated by **Stephen S. Mitchell** before acceptance into the applicable codebase or design workflow.

AI/LLM-assisted output is evaluated for technical correctness, compatibility, maintainability, performance, security, design intent, and conformance with the architecture, requirements, CAD standards, computational methods, coding standards, and intended behavior of the applicable project.

AI/LLM tools may also be used to assist with repetitive development tasks, boilerplate code, implementation alternatives, error analysis, technical explanations, documentation preparation, and exploration of possible solutions. Final technical and design decisions are made by **Stephen S. Mitchell**.

AI/LLM-assisted documentation, source-code comments, examples, README content, tutorials, project descriptions, release information, and other written materials are manually reviewed, edited, corrected, and adapted before publication.

The extent and nature of AI/LLM assistance may vary between repositories. Unless expressly stated otherwise within a specific repository, AI/LLM assistance should be understood as a supporting development tool rather than as the designer, developer, maintainer, or author responsible for the project.

**Stephen S. Mitchell retains final responsibility for the CAD designs, computational design methods, software architecture, source code, algorithms, automation workflows, functionality, integrations, testing, documentation, releases, maintenance, and final project content published through this GitHub organization.**
